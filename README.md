# LSTM-Long-Short-Term-Memory-for-time-series-forecasting-of-air-temperature-in-the-city-of-Bel-m-PA-.
This LSTM (Long Short-Term Memory) model was developed to forecast air temperature time series in Belém (PA), Brazil. Leveraging historical weather data, the model captures temporal dependencies and trends, enabling accurate short- and medium-term temperature predictions in a tropical climate.
